# Inventor 2027 API Index

Curated entry point for the DXF-exporter/add-in API surface. Namespace for the listed Inventor API types is `Inventor`. The local reference used for this pass is the Autodesk-shipped Inventor 2027 API Help (`admapi_31_0.chm`) plus the installed `Autodesk.Inventor.Interop.xml` and matching `Autodesk.Inventor.Interop.dll` (version `31.10.26700.0`).

## Status vocabulary

- **Verified from Inventor 2027 Reference** — exact symbol/signature checked in the local 2027 API Help or matching 2027 interop metadata.
- **Verified from Inventor 2027 SDK Sample** — usage seen in an Autodesk SDK sample. No DeveloperTools samples were installed for this pass; do not assign this status based on an API Help sample.
- **Compile Verified** — the example project builds against the installed 2027 interop assembly.
- **Inventor Runtime Tested** — executed inside Inventor 2027.
- **Unverified** — missing evidence. Do not invent a signature.

Statuses are per row. A reference verification does not imply compile or Inventor runtime verification. See [`API_VERIFICATION.md`](./API_VERIFICATION.md).
